# Функциональное тестирование

## Сценарии

| ID | Название | Шаги | Ожидаемый результат | Статус |
|----|----------|------|---------------------|--------|
| FT-01 | Создание квеста | 1. Ввести `/quest` | Появляется сообщение с квестом, квест сохраняется в БД | ✅ |
| FT-02 | Отмена квеста | 1. Ввести `/quest cancel` | Квест отменён, статус FAILED | ✅ |
| FT-03 | Завершение квеста | 1. Выполнить условие квеста | Начислен опыт, статус COMPLETED | ✅ |
| FT-04 | Просмотр дашборда | 1. Открыть http://localhost:8080 | Данные из БД отображаются на всех страницах | ✅ |
| FT-05 | Обучение модели | 1. Нажать "Обновить модель" | Accuracy и F1 Score обновляются | ✅ |
| FT-06 | Настройки | 1. Изменить порог → Сохранить | Настройки сохраняются в БД | ✅ |

## Среда тестирования

- Docker Compose (PostgreSQL, ML-сервис, Minecraft, Дашборд)
- Клиент Minecraft 1.21.11
- Браузер (дашборд)

## Результат

Все сценарии выполнены успешно. Система работает стабильно.
